# Scale Controller Rev-A — Status, 17 September 2026

Supersedes `status-2026-09-15.md`. Board fully routed, DRC 0 errors / 0 unrouted,
5 benign warnings, everything pushed (`origin/main` = c55ba90).

## Changes since 15 Sept

- **Load-cell sockets** → JST PH B3B-PH-K (2.0 mm, friction lock). One connector pair
  is inverted on the board (J3/J7 vs J5/J8) so all four half-bridge cells plug in
  identically: pin 1 white, pin 2 red (centre tap), pin 3 black. Legend on silk.
  Rows at 5.7 mm pitch; NT2/NT3 moved above the column.
- **USB-C** → HRO TYPE-C-31-M-12 (SMD signal pins, four PTH shell legs), replacing the
  Bel hybrid whose staggered PTH row failed PCBWay's hole-spacing and ring limits.
  Added R1/R2 5.1 kΩ CC pull-downs (board now powers from C-to-C cables and chargers).
  Rendered with the GCT USB4105 3D model as stand-in (KiCad ships no HRO model).
- **Display header J9** moved to the **back side**, pin order **GND, 3V3, SCL, SDA**
  to match the Hosyond 0.96" I2C module. The module plugs in from below and lies
  flat under the board, clear of the load-cell sockets. DISP1 is a pad-less
  placeholder footprint + model for fit checks only (nominal 27 × 27.5 mm).
- **DFM for PCBWay**: all vias 0.6/0.3 mm (0.15 mm ring; one 0.55/0.3 at U4 pad 8),
  ESP32 module ground-grid pads 0.6 mm, copper-to-edge rule 0.3 mm, net-class vias
  0.6/0.3, U4 pin 12 grounded into the centre pad (via in pad).
- Silkscreen labels; standard-library footprints refreshed; E+/E− naming tidied.
